# Dagsverk 0.1.0

- Track separate jobs and contracts with isolated workspaces
- Record workdays in ledger and calendar views
- Match Tidverk payroll, overtime, OB, time balance, tax, and holiday calculations
- Export matching Excel reports and OpenDocument spreadsheets
- Store all data locally with backup, restore, and Tidverk import support
- Install and update native Windows and Linux builds with Velopack
