# Dagsverk 0.1.9

- A day can have more than one work period, for split shifts. The gaps between periods are unpaid
- Lunch can be any number of minutes, not only the presets
- Workspaces are now called profiles. The first start and New profile use one short form
- The new Profile page holds a profile's details, schedule, pay, tax, and overtime. Settings holds only app-wide preferences and backups
- A profile's name, employer, and your name can be edited after it is created
- Profiles with no fixed schedule hide expected hours and the time balance, and pay overtime
- The day editor shows times first and no longer has fixed 08:00 presets
- Fix: a profile with no workdays no longer treats Sundays as workdays
