# Dagsverk 0.1.10

- Hourly profiles can add Swedish holiday pay (semesterersättning) on top of the pay. Pick none, 12 % (legal minimum), 12.72 % (hotel and restaurant agreement), or another percent
- New hourly profiles start with 12 % holiday pay. Existing profiles keep 0 %
- The net pay card shows the holiday pay part when you point at the gross amount
- Fix: profiles with no fixed schedule no longer count every hour as overtime
- Fix: 0 hours per workday no longer changes to 8 when you save
